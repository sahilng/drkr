# Security reporting

drkr handles webpage appearance locally and does not require credentials or a backend.

If you discover a vulnerability, use this repository's **Security → Report a vulnerability** button when available. Do not post passwords, tokens, private browsing content, or an exploitable vulnerability in a public issue.

If private reporting is unavailable, open a minimal issue titled “Request private security contact” without vulnerability details or sensitive data. The maintainer can arrange a private reporting channel before you share the details.

No response-time guarantee is offered for this volunteer-maintained project. Only the current development version is actively maintained.
