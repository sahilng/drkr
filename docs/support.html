A calmer setup, too.

Drkr is maintained by sahilng. Support and compatibility reports are handled through GitHub Issues.

Drkr is currently in development. The source is public; the Mac App Store version is not available yet. You can test the development build using the repository instructions.

Get started

  1. Open Safari → Settings → Extensions and enable Drkr after installing its containing Mac app.
  2. Allow access to the websites you want to theme. Private-browsing access is optional.
  3. Reload tabs opened before installation. Click the moon in Safari’s toolbar to choose On, System, or Off.

For a development install, follow the repository’s temporary-extension instructions. These builds require Safari’s unsigned-extension authorization and expire when Safari quits or after 24 hours.

Common questions

A website looks wrong. How do I restore it?

Open Drkr’s toolbar popup and choose Keep original under Appearance for that website. Choose Use global setting to remove the override later.

Nothing changes when I turn Drkr on.

Check Safari Settings → Extensions and the website-access permissions. Reload the webpage. Safari’s internal pages cannot be themed. If a light website is misidentified as dark, turn off Respect existing dark themes in the popup.

Why does Safari mention sensitive information?

Changing webpage appearance requires permission to read and alter webpages. Safari describes the broad capability of that permission. Drkr uses page structure and computed colors; it does not transmit webpage content, passwords, form values, or browsing history. Read the privacy policy for details.

I still see a flash, a light panel, or a dark logo.

Drkr reduces startup flashes, but Safari can draw its own background before extensions run. Some artwork and author-important panels keep their original look for readability. Report a reproducible issue with the website URL and your Safari version.

Does it work on iPhone or iPad?

This version targets Safari on Mac. iPhone and iPad support is not part of the current release.

Report a problem

Include the website URL, Drkr version, Safari/macOS version, appearance setting, and a few steps to reproduce the problem.

GitHub issues are public. Remove account details and private content from screenshots before attaching them.
