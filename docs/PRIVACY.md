# drkr privacy policy

Last updated: October 26, 2026. Applies to drkr 0.2.0.

drkr changes the appearance of websites in Safari. It works locally on your device. It has no server, accounts, advertising, analytics, or telemetry. It does not transmit website content, browsing history, passwords, form entries, or payment information.

## Website access

Safari requests permission to read and change webpages because drkr inspects page structure and computed colors, then inserts dark styling. That permission is broader than the information drkr uses. drkr does not intentionally read form values, password fields, or the text of your messages. Safari controls which websites the extension may access.

drkr sometimes resolves CSS colors using a detached one-pixel canvas. It paints only a color swatch it creates itself; it does not sample page images or screenshots.

## Stored information

drkr stores your global appearance setting, whether to respect existing dark themes, and exact hostnames for which you set a website override. These preferences stay in Safari extension-local storage. drkr does not sync or transmit them. Diagnostic timing counters exist only in page memory and are discarded with the page.

Private-browsing access is optional. When allowed, drkr uses the same local preferences and does not create a browsing log. Hostnames you explicitly save as overrides remain in preferences until you remove the override or extension data.

## Your choices

Choose “Use global setting” to remove a saved website override. Turn drkr off in its popup, revoke website/private-browsing access in Safari Settings, or uninstall the extension. Follow Safari's controls to remove extension data.

## Support and updates

drkr is maintained by [sahilng](https://github.com/sahilng). Questions can be raised through [GitHub Issues](https://github.com/sahilng/drkr/issues/new/choose); issues are public, so remove private data before submitting a report. The hosted version of this policy is [here](https://drkr.space/privacy.html). GitHub Pages handles website connections under GitHub's privacy statement. The extension does not contact that site automatically. Review this policy whenever code or data practices change.
