Privacy policy

Last updated October 26, 2026 · Applies to the current Drkr development version

Drkr is an open-source Safari dark mode extension maintained by sahilng. It changes website appearance locally on your device.

No accounts, advertising, analytics, telemetry, or backend. Drkr does not transmit website content, browsing history, passwords, form entries, or payment information.

Website access

Safari asks for permission to read and alter webpages because Drkr inspects page structure and computed colors, then inserts dark styling. That permission is broader than the information Drkr uses. Drkr does not intentionally read form values, password fields, or the text of your messages. You choose which websites it can access in Safari Settings.

Drkr sometimes resolves CSS colors using a detached one-pixel canvas. It paints only a color swatch it creates itself; it does not sample page images or screenshots.

Information stored on your device

Drkr saves your global appearance setting, whether to respect existing dark themes, and exact hostnames for which you explicitly set website overrides. These preferences stay in Safari extension-local storage. Drkr does not sync or transmit them.

Diagnostic timing counters exist only in page memory and disappear when that page is discarded. They are not sent anywhere.

Private browsing

Private-browsing access is optional. If you allow it, Drkr uses the same local preferences and does not create a browsing log. Hostnames you explicitly save as website overrides remain in preferences until you remove them or delete extension data.

Your choices

Choose Use global setting to remove a saved website override. You can turn Drkr off, revoke website or private-browsing access in Safari Settings, or uninstall the extension. Use Safari’s controls to remove extension data.

This website and support

These pages are hosted on GitHub Pages. GitHub handles website connections under its privacy statement. This website adds no analytics, tracking scripts, or forms. The extension does not contact this website automatically.

If you choose to open a support issue, its content is stored publicly by GitHub. Remove personal information from reports. Questions about this policy can be raised through GitHub Issues.

Changes to this policy

Changes to Drkr’s data practices will be reflected here with an updated date. The extension’s source is available in the public repository.
