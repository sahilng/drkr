Drkr is enabled. Open a website to try it.

One more step: enable Drkr in Safari.

  1. Enable Drkr in Safari Extensions Settings.
  2. Allow access to the websites you want to theme. Private-browsing access is optional.
  3. Reload existing tabs. Click the moon in Safari’s toolbar for On, System, and Off, or set a website override.
Help and compatibility

If a website looks wrong, choose Keep original for that website. If a light website is incorrectly detected as dark, turn off Respect existing dark themes.

Safari’s built-in pages cannot be themed. Some artwork and author-important panels keep their original appearance for readability. Closed shadow roots and complex canvas apps may need site-specific support.

Development builds need Safari’s Allow Unsigned Extensions option. A temporary extension is separate from this packaged app; keep only one copy enabled while testing.

Privacy

Drkr inspects webpage structure and colors to change appearance. Safari’s access warning describes the full capability of that permission. Drkr does not transmit page content, browsing history, form values, passwords, or payment information.

Your global mode, dark-theme preference, and hostnames with website overrides stay in Safari extension-local storage. There are no accounts, analytics, tracking, or servers. Private browsing is optional; explicit website overrides are saved until removed.

Choose Use global setting to remove a website override. Revoke website access or disable/uninstall Drkr in Safari Settings.

Made for quieter browsing. All processing stays on your device.
