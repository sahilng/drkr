# macOS App Store screenshots

Captured directly from Safari 26.6.2 on October 26, 2026 with the signed drkr 0.2.0 packaged extension enabled. Both JPEGs are 2880×1800 and are unedited captures of an actual Safari window. The browser window was resized and the local page displayed at Safari's 85% zoom; the extension popup keeps its native size.

1. `01-controls.jpg`: the real extension popup over the reading page.
2. `02-reading.jpg`: themed text, an entered form value, original embedded color artwork, and content added by the page's button.

All page content and artwork are original to this repository, from `tests/reading.html`. The page is explicitly labeled as an extension demonstration. It is a real test website being themed by the extension, not a mockup of Safari or drkr. No accounts, private messages, or third-party articles are shown. Source and original demonstration content are MIT licensed; Apple UI remains Apple's property.

These two files are uploaded to the private English (U.S.) macOS version draft in App Store Connect. The popup and theming code are unchanged in release candidate 1.0.0; its native version/menu metadata changes are not shown in these screenshots. Re-capture them if the visible release UI changes. Wikipedia captures in the ignored build folder are QA references and have not been uploaded.
